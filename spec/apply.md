# Apply Spec - Implementation Roadmap

## 第一階段：環境初始化與資料結構
1.  **[DONE] 實作真實訓練任務**：已成功串接 `ultralytics` 並強制使用本地權重解決卡死問題。
2.  **[DONE] 穩定性與併發優化**：導入 UUID 命名機制，並實作 `CUDA/CPU` 智能自動回退機制。
3.  **[DONE] 交互回饋升級**：完成「高對比度儀表板」、「白色狀態標籤」與「非同步硬體監控面板」。
4.  **[DONE] 訓練生命週期管理**：實作開始、暫停、恢復與終止功能，整合品質評價系統。

## 第二階段：後端開發 (FastAPI)
1.  **推理引擎**: 實現 `YOLOInference` 類別，封裝 `model.predict()` 並將結果轉換為 Web 友好的 JSON。
2.  **訓練管理器**:
    - 實作資料集掃描邏輯。
    - 建立 `DataSplitter` 工具：自動檢查 `train/val` 結構，若缺失則按 80/20 分割。
    - 使用 `multiprocessing` 或背景任務啟動 `model.train()`，透過檔案或記憶體快取傳遞訓練狀態。
3.  **API 開發**: 完成圖片上傳、資料集解析、訓練控制（啟動/暫停/終止）、圖表數據讀取之 API。

## 第三階段：前端開發 (React + Tech UI)
1.  **建立項目**: 使用 `npm create vite@latest web -- --template react`。
2.  **UI 基礎**:
    - 設定 `index.css` 全域變數、流體漸層背景與科技點陣特效。
    - 使用 `Outfit` 字體與漸層流光文字實作高階標題。
    - 設計 `Sidebar` 組件與頁面切換邏輯。
3.  **頁面實現**:
    - **驗證頁面**: 實作 `Single` 與 `Batch` 獨立頁面，並加入參數同步與 Tooltip 指引。
    - **訓練頁面**: 實作資料夾選取 (webkitdirectory)、訓練即時狀態文字、可暫停/終止之 Chart.js 模擬器。
    - **成果驗收**: 實作「模型品質評價區塊」與「自動儲存至選單」邏輯。
4.  **互動強化**: 加入進度條組件、錯誤警示彈窗 (Toast/Alert)。

## 第四階段：系統集成與優化
1.  **主啟動腳本**: 編寫 `run.py` 同時啟動後端與打開瀏覽器頁面。
2.  **效能調優**: 檢查 GPU 使用情況，優化大型圖片上傳的讀取速度。
3.  **測試**:
    - 測試不同圖片格式 (JPG/BMP/PNG) 的相容性。
    - 模擬資料集缺失 `val` 情況的自動分割測試。

## 第五階段：交付與驗證
- 確保所有按鈕具有互動回饋。
- 驗證離線環境下的運行完整性。
