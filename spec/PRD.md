# AI Detector - 產品需求文件 (PRD) V4.0

## 一、 產品願景
打造一個整合 YOLO 推理能力與直覺管理介面的 AI 影像平台，達成「數據管理 -> 精確標記 -> 模型訓練 -> 驗證佈署」的完整自動化生命週期。

## 二、 核心功能規格 (模組化對照)

### 1. 資料集管理模組 (Dataset Hub)
*   **前端功能 (`datasets.html`)**: 
    *   卡片式網格展示資料集，即時渲染標記進度條（已標記/總數）。
    *   支援資料集建立、路徑匯入及選單式刪除。
*   **後端邏輯 (`ai_analyzer.py`)**: 
    *   遞迴掃描 `images/` 與 `labels/` 子目錄。
    *   標記判定：檔案大小 > 0 bytes 且副檔名為 `.txt` 才計入「已標記」。
*   **資料儲存**: 所有資料存放於 `data/datasets/[資料集名稱]/`，維持 YOLO 原生目錄結構。

### 2. 影像標記任務 (Annotation Task)
*   **前端功能 (`labeling.html`)**: 
    *   **高階畫布**: 支援框選、四角控制點 (Handles) 微調、類別計數統計。
    *   **智慧導航**: 進度滑桿跳轉、自動尋找下一個未標記圖片 (🔍 按鈕)。
*   **後端邏輯 (`main.py`)**: 
    *   `/api/datasets/save_label`: 接收座標並轉換為歸一化 YOLO 格式。
    *   **同步機制**: 監聽 `REFRESH_DATA` 訊號，於自動標記完成後即時重載畫布內容。
*   **資料儲存**: 標記內容寫入與圖檔同名的 `.txt` 檔案。

### 3. 模型訓練中心 (Training Center)
*   **前端功能 (`index_v3.html` -> Train Page)**: 
    *   配置訓練參數（模型、輪次、批次、解析度、早停 `patience`）。
    *   **健康診斷**: 啟動前自動檢查圖片與標記的配對狀態，預覽 `data.yaml`。
*   **後端邏輯 (`trainer.py`)**: 
    *   自動生成訓練組態檔，在獨立背景執行序執行訓練。
    *   **自動佈署**: 結束後自動將 `best.pt` 權重複製至 `models/` 目錄並自動命名。
*   **資料儲存**: 訓練日誌儲存於 `runs/train/exp/`。

### 4. 智慧助理模組 (AI Vision Assistant)
* **自動標記指令 (Auto-Labeling)**: 使用者可透過自然語言要求「幫我標記 [資料集]」。
* **後端標記引擎**:
    * **自動類別建立**: 支援在標記過程中自動將新偵測到的物件加入 `classes.txt`。
    * **NMS 優化**: 針對自動標記優化重疊過濾，大幅減少重複框產生。

### 5. 資料集健康診斷系統 (AI Dataset Health) [NEW]
* **AI 助理快速門診 (Chatbox Entry)**:
    * **自然語言診斷**: 支援指令「幫我分析 [資料集名稱] 的健康度」。
    * **即時體檢卡片**: AI 回傳包含「健康分數儀表板」與「三大核心問題」的互動卡片。
    * **行動處方箋**: LLM 根據數據提供具體建議（如：建議增加特定類別的圖片）。
* **深度分析儀表板 (Three Dots Entry)**:
    * **互動式類別分布圖**: 使用 Chart.js 呈現類別平衡度、框大小分佈。
    * **問題圖片藝廊 (Problem Gallery)**: 自動挑選出「框過小」、「嚴重重疊」、「疑似標錯」的圖片，點擊可直接進入標記頁面修正。
    * **類別清理工具**: 支援 AI 輔助的類別合併建議（例如合併 `car` 與 `Car`）。

### 6. 模型效能診斷系統 (AI Model Performance Diagnosis) [NEW]
* **深度診斷儀表板 (Evaluation Dashboard)**:
    * **混淆矩陣 (Confusion Matrix)**: 以熱力圖呈現模型「看錯」的傾向（例如常把 A 看成 B）。
    * **類別弱點報告**: 自動計算各類別的 F1-Score 與精準度，將表現最差的類別標示為「亟待優化」。
    * **P-R 曲線與 F1-Confidence 圖**: 視覺化模型在不同閾值下的最佳工作點。
* **錯誤樣本追蹤 (Error Sample Tracking)**:
    * **False Positives (誤報) 藝廊**: 展示模型「憑空想像」出的物件圖片。
    * **False Negatives (漏報) 藝廊**: 展示模型「視而不見」的物件圖片。
    * **AI 歸因建議**: AI 助理分析錯誤樣本，給出建議（如：「樣本過小導致漏報」或「背景過於複雜導致誤報」）。

### 7. 影像驗證與佈署模組 (Verify & Deploy)
*   **前端功能 (`index_v3.html` -> Verify Pages)**: 
    *   單張上傳推理、全資料夾批量掃描。
    *   即時動態調整 Confidence 與 IoU 閾值。
*   **後端邏輯 (`inferencer.py`)**: 
    *   執行 YOLO 推理，返回 JSON 座標與畫好的預覽圖 URL。
*   **佈署工具**: 一鍵匯出模型為 ONNX 或 TensorRT 格式，支援邊緣裝置部署。

## 三、 技術架構與穩定性規範
1. **多埠口穩定架構**:
    *   **Port 8000**: Shell 殼層與 AI 助手。
    *   **Port 8001/8002/8003**: 獨立處理資料集、標記與訓練 API。
2. **跨頁面即時同步**: 透過 `window.postMessage` 實現跨埠口資料通訊（例如標記儲存後，資料集列表同步更新）。
3. **系統啟動序列**: 採用「子系統優先」啟動 (8001-8003)，最後開啟主入口 (8000)，解決連線被拒問題。
4. **硬體狀態監控**: 調用 `psutil` 監測 CPU/RAM，調用 `torch.cuda` 監測 GPU。
