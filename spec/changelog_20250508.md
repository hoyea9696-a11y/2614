# Changelog - 2025/05/11 V4 穩定修正

## 問題根因分析

### 自動標記「只報成功，實際 0 檔案」
- `main.py` 呼叫的是 `auto_label_gemini`
- Gemini API 回傳格式不對 → 觸發 YOLO fallback
- YOLO fallback (`_label_single_image_yolo`) 用 `target_classes` 建立 `class_map`
- 資料集沒有 `classes.txt` → `target_classes = []` → `class_map = {}`
- YOLO 偵測到 car/truck，但 `"car" not in {}` → 全部丟棄
- `labeled_count += 1` 仍然遞增 → 終端機顯示 61 成功，磁碟 0 檔案

### 第一次進入頁面拒絕連線
- iframe src 在 HTML 靜態寫入 + JS 二次覆寫 → 雙重載入競態
- 啟動順序 8000 先開 → 子埠口 8001/8002 還沒啟動就被訪問
