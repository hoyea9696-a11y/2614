# AI Detector

AI Detector 是一個以 Python 與 YOLO 為基礎的影像辨識平台，提供從資料集整理、模型訓練、模型評估到影像驗證的操作流程。

本專案的目標是讓使用者能透過網頁介面完成基本的 YOLO 訓練與驗證工作，並在訓練前確認資料集與參數，避免直接執行造成不必要的時間成本。

## 主要功能

- 匯入與管理影像資料集
- 影像標註與 YOLO 格式資料整理
- 選擇 YOLOv9 模型與訓練參數
- 啟動 YOLO 模型訓練並查看訓練進度
- 查看模型評估結果，例如 mAP、Loss 與混淆矩陣
- 上傳單張圖片進行辨識驗證
- 上傳資料夾進行批量影像驗證
- 透過 LLM 輔助查看訓練流程的規劃、狀態與操作資訊
- 在啟動訓練前加入使用者確認，避免系統未確認條件就直接執行

## 操作流程

```text
匯入資料集
→ 整理或標註影像
→ 選擇模型與訓練參數
→ 確認資料與設定
→ 使用者確認後開始訓練
→ 查看模型評估結果
→ 上傳圖片或資料夾進行驗證
