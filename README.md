# AI Detector

AI Detector 是一個以 Python、YOLO 與 LangGraph 建立的本機影像辨識平台。

系統將影像資料集管理、標註、YOLO 模型訓練、模型評估與影像驗證整合到網頁介面中；並透過 LangGraph 控制 LLM 輔助流程，讓訓練前的資料檢查、參數確認與使用者確認能依序進行。

## 專案功能

- 匯入與管理影像資料集
- 建立與編輯 YOLO 格式標註
- 支援 AI 輔助自動標註
- 檢查資料集健康度，例如影像與標註資料狀況
- 選擇 YOLOv9 模型與訓練參數
- 啟動、查看與停止模型訓練
- 查看模型評估結果與訓練圖表
- 查看 mAP、Loss、F1、Precision、Recall 與混淆矩陣等結果
- 上傳單張圖片進行影像辨識驗證
- 上傳資料夾進行批量影像驗證
- 使用 LLM 協助理解需求、規劃流程與說明模型結果
- 顯示 AI 工作流程的執行狀態與處理紀錄

## 系統流程

```text
匯入資料集
→ 整理或編輯標註
→ 檢查資料集狀況
→ 選擇 YOLO 模型與訓練參數
→ 使用者確認
→ 模型訓練
→ 模型評估
→ 單張或批量影像驗證
```

## LangGraph 在本專案中的用途

LangGraph 是本專案用來管理 AI 工作流程的框架。

它不負責訓練 YOLO 模型，也不是單純讓 LLM 回答問題；它主要負責保存流程狀態、決定下一步、設定停止條件，以及在重要操作前要求使用者確認。

當使用者提出模型訓練需求時，系統會將流程拆成多個步驟：

```text
使用者提出需求
→ LLM 理解需求並規劃處理步驟
→ 確認資料集是否存在
→ 檢查資料集健康度
→ 確認模型與訓練參數
→ 暫停並等待使用者確認
→ 執行 YOLO 訓練
→ 評估模型結果
```

### 流程控制方式

- 若資料集不存在或沒有影像，系統會停止後續訓練並提示使用者先上傳資料。
- 訓練前會先檢查資料與參數，避免未確認條件就直接訓練。
- 啟動訓練前，系統會暫停並要求使用者確認。
- 使用者確認後，系統會從原本暫停的位置繼續執行，而不是重新開始整個流程。
- 系統使用 SQLite checkpoint 保存流程狀態，讓確認流程與對話狀態可以被追蹤。
- 前端會接收流程狀態與執行紀錄，讓使用者能了解目前由哪個步驟處理、下一步會做什麼。

這樣的設計是為了避免 LLM 在沒有資料、參數不完整，或尚未取得使用者同意的情況下，直接執行耗時的訓練操作。

## 安裝方式

### 環境需求

- Windows
- Python 3.9 以上
- 建議使用 NVIDIA GPU 進行模型訓練
- Git

### 下載專案

```bash
git clone https://github.com/hoyea9696-a11y/2614.git
cd 2614
```

### 安裝套件

執行：

```text
setup.bat
```

此步驟會建立 Python 虛擬環境，並依照 `requirements.txt` 安裝所需套件。

### 啟動系統

執行：

```text
run.bat
```

系統啟動後，在瀏覽器開啟：

```text
http://localhost:8000
```

## 使用方式

### 1. 匯入資料集

進入資料集頁面，建立資料集名稱並上傳影像資料。系統會將資料集整理至本機資料目錄。

### 2. 標註與資料檢查

可在標註頁面建立或修改 YOLO 格式標註，也可以使用 AI 輔助標註功能。完成後，可查看資料集健康度與基本資料狀況。

### 3. 設定與訓練模型

選擇資料集、YOLOv9 模型與訓練參數後，系統會顯示設定資訊。使用者確認後，才會開始模型訓練。

### 4. 評估模型

訓練完成後，可查看模型評估資料與圖表，例如：

- mAP50
- mAP50-95
- Precision
- Recall
- F1 Curve
- Precision-Recall Curve
- Confusion Matrix
- Training / Validation Loss

### 5. 影像驗證

使用者可選擇模型權重後：

- 上傳單張圖片進行快速驗證。
- 上傳資料夾進行批量驗證。
- 查看辨識結果與標記後的影像。

## LLM 設定

LLM 輔助功能可搭配 Gemini、OpenAI 或 Groq 相容模型使用。

請將 API 金鑰與模型設定放在專案根目錄的 `.env` 檔案中。由於 `.env` 可能包含敏感金鑰，請勿提交到 GitHub。

## 注意事項

- 請勿將公司機密影像、敏感資料或 API 金鑰上傳至公開儲存庫。
- `data/datasets/`、`models/`、`runs/`、`.env` 與 `venv/` 已適合保留在本機，不建議直接提交。
- 模型訓練時間與效果會受到資料量、標註品質、模型大小與硬體環境影響。
- 本專案的 LLM 功能用於協助理解需求、規劃操作流程與說明結果；重要訓練操作仍應由使用者確認。
